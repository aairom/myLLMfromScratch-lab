Abstract

These four components are the working parts of every transformer block. Attention lets each position read information from the others. Multiple heads let it read several kinds of information at once. Layer normalisation keeps activations at a usable scale as layers are stacked, and the feed-forward network transforms each position on its own. This document derives each from first principles, explains why the 1/dk scaling and the causal mask are needed, and ties the algebra to the parameter counts of the default model (33,280 parameters in attention, 66,176 in the feed-forward layers).

Scaled dot-product attention

The idea

Attention was introduced for machine translation by Bahdanau, Cho and Bengio (2015) as a soft alignment between source and target words, and became the sole sequence-mixing mechanism in the Transformer (Vaswani et al., 2017). For a sequence of T vectors, every position produces three vectors with learned linear maps:

  • a query 𝐪t: what this position is looking for;
  • a key 𝐤s: what position s offers to be found by;
  • a value 𝐯s: the content position s passes on if selected.

Stacking them as matrices Q,K,V∈ℝT×dk, the output is

Attention(Q,K,V)=softmax(QK⊤dk+M)V.

Row t of QK⊤ contains the dot products of query t with every key. The softmax turns that row into a probability distribution over positions (the attention weights), and the output at t is the corresponding weighted average of the value vectors. M is the mask described below.

Why divide by dk

Suppose the components of 𝐪 and 𝐤 are independent with zero mean and unit variance. Then the dot product 𝐪·𝐤=∑i=1dkqiki has

𝔼[𝐪·𝐤]=0,Var[𝐪·𝐤]=dk.

Its standard deviation grows like dk. Large scores push the softmax into a saturated regime in which one weight is almost 1 and the others almost 0, and the gradient through the softmax nearly vanishes. Dividing by dk restores unit variance. This was checked numerically for dk∈{4,16,64,256}: the variance of the raw dot product is close to dk in every case, and the variance after scaling is about 1.00 in every case.

The causal mask

A language model predicts token t+1 from tokens 1,…,t. If position t could attend to later positions, the answer would be available in the input and the model would learn to copy rather than predict. The mask enforces causality:

Mts={0s≤t−∞s>t.

Adding −∞ before the softmax gives masked positions exactly zero weight. The attention matrix is therefore lower-triangular, and row t always contains at least the position t itself, so no row is entirely masked in normal use. The implementation still converts a hypothetical fully masked row to zeros instead of NaN.

Causality is a testable property

Changing any token after position t must leave all outputs at positions ≤t unchanged. The test suite checks exactly this, which is stronger than inspecting the mask visually.

Cost

The score matrix has T2 entries per head, so time and memory grow quadratically with the sequence length. For the context of 64 tokens this is negligible; for long documents it is the central bottleneck that motivates sparse and linear attention variants (Child et al., 2019; Katharopoulos et al., 2020).

Multi-head attention

A single attention distribution can express only one weighting of the past at a time. Multi-head attention runs h attentions in parallel on lower-dimensional projections and combines the results:

headi=Attention(XWiQ,XWiK,XWiV),MHA(X)=Concat(head1,…,headh)WO,

with dk=dmodel/h. For the default model dmodel=64 and h=4, so each head has dk=16 dimensions.

Cost is unchanged. Splitting the width into heads keeps the total size of the projections the same as one full-width head: four d×d matrices (WQ,WK,WV,WO) plus biases, that is 4(d2+d) parameters, which is 16,640 per layer for d=64. Heads are therefore a way to specialise the same capacity, not to add more.

What heads learn. Analyses of trained transformers (Clark et al., 2019; Voita et al., 2019) found heads that attend to the previous token, to the same word elsewhere, to syntactic partners, or to separators; some heads can be removed with little loss. In the very small model used here the picture after 300 training steps is modest. Measured on the first 48 characters of the corpus, averaging over heads and over positions 8 and later, the entropy of the attention distribution is about 3.25 nats at initialisation, which equals the entropy of a perfectly uniform distribution over the visible past. After training, layer 1 is still essentially uniform (3.25 nats), while layer 0 has become sharper (about 2.76 nats, and its largest weight rises from about 0.04 to about 0.16). So only the first layer has begun to favour particular positions; do not expect the clean head specialisation seen in large models.

Layer normalisation

Definition

Deep networks train more easily when each layer's inputs stay in a stable range. Ba, Kiros and Hinton (2016) proposed normalising across the features of one token rather than across the batch. For a vector 𝐱∈ℝd:

μ=1d∑j=1dxj,σ2=1d∑j=1d(xj−μ)2,x^j=xj−μσ2+ε,yj=γjx^j+βj.

The variance is the biased estimate (division by d), ε=10−5 prevents division by zero, and γ,β∈ℝd are learned scale and shift, initialised to 1 and 0. A worked example for 𝐱=(1,2,3,4): μ=2.5, σ2=1.25, and the normalised vector is (−1.342,−0.447,0.447,1.342).

Why it fits language models

Unlike batch normalisation, the statistics depend on a single token, so the computation is identical during training and inference, does not depend on batch size, and works for sequences of any length. Each LayerNorm has 2d parameters; the default model has 640 in total (two per block plus one final).

Pre-norm and post-norm

The original Transformer applied the normalisation after each sub-layer (post-norm). GPT-2 and most later models apply it before the sub-layer, inside the residual branch (pre-norm). Xiong et al. (2020) showed that pre-norm keeps gradients well-scaled at initialisation and removes the need for a long learning-rate warm-up. This project is pre-norm: the block computes 𝐱+Sublayer(LN(𝐱)), which the next sub-task assembles.

The position-wise feed-forward network

Attention is a weighted average, which is linear in the values. The non-linearity of a transformer lives in the feed-forward network, applied to each position independently with the same weights:

FFN(𝐱)=W2ϕ(W1𝐱+𝐛1)+𝐛2,W1∈ℝdff×d,W2∈ℝd×dff,dff=4d.

For the default model dff=256, which gives 33,088 parameters per layer, about twice the attention parameters of the same layer. Feed-forward layers hold most of a transformer's parameters; Geva et al. (2021) interpret them as key-value memories that store associations learned from the data.

The activation function

The default activation is GELU (Hendrycks and Gimpel, 2016), which weights an input by the probability that a standard normal variable is below it:

GELU(x)=xΦ(x)≈0.5x(1+tanh[2/π(x+0.044715x3)]).

The implementation uses the tanh approximation, as in GPT-2. Compared with ReLU, max(0,x), GELU is smooth and lets small negative inputs pass with a small weight, which gives non-zero gradients where ReLU has none. ReLU remains available as an option.

What the pieces do together

Component Mixes across positions? Non-linear? Learnable parameters (d=64)
Attention (all heads) yes only through the softmax 16,640 per layer
LayerNorm no yes (normalisation) 128 per norm
Feed-forward no yes (GELU) 33,088 per layer

The division of labour is the central design idea: attention moves information between positions, and the feed-forward network processes it at each position.

Limitations

  1. Quadratic cost in sequence length, as discussed above.
  2. No built-in order. Attention is permutation-equivariant; the order comes only from the positional encoding of the previous sub-task.
  3. Interpretation caution. Attention weights show where information is read from, not necessarily why an output was produced (Jain and Wallace, 2019). They are a diagnostic, not an explanation.
  4. Untrained patterns. The interface lets learners inspect attention on an untrained layer; those patterns are random-projection artefacts, not learned structure.
