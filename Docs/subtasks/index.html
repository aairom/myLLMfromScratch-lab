Each sub-task has two standalone documents: a scientific explanation (concepts, mathematics, significance and limits) and an implementation guide (where the code sits, how data flows, which structures exist, how it is configured and how it behaves at run time). Every page is one self-contained HTML file: no network, no scripts, readable offline.

How these pages are made

The Markdown sources live next to the pages. scripts/build-docs.sh converts them with the docsgen package: formulas become MathML, code excerpts are read from the live source with inspect, and every number is looked up from the code or the recorded run. The build then validates each page (one h1, heading order, accessible SVG, no external resources, no unresolved placeholders).
